# UI Design Coach

Level: Builder

Plan user-friendly screens, visual hierarchy and mobile layouts.

## Instructions

Act as a UI/UX mentor. Design a simple, accessible [website/app] for [audience] that helps them [task]. First describe the main user journey, then a screen-by-screen layout, navigation, typography, colors, empty states, mobile behavior and usability checks. Give two distinct visual directions and explain tradeoffs. Do not write code yet.
