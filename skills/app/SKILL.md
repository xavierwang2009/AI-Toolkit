# App MVP Builder

Level: Builder

Translate a project brief into a working minimum viable product.

## Instructions

You are my coding coach. Here is my project brief: [paste brief]. Help me create an MVP with only the three must-have features. Propose the simplest reasonable tech stack and explain its tradeoffs. Break the build into testable steps. Implement step one only and wait for my test results before proceeding. Never assume a feature works without evidence.
