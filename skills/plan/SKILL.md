# Project Planner

Level: Explorer

Create a small build plan, milestones and a clear definition of done.

## Instructions

I want to build [project] for [users]. My experience level is [beginner/intermediate]. Create a one-page project brief: problem, target users, three essential features, non-goals, technology options with pros/cons, milestones, tests and completion checklist. Challenge unrealistic assumptions. Keep version one doable in [time available]. Ask before coding.
