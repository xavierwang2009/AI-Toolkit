# My Everyday Helper

Level: Builder

Identify one recurring everyday problem and create a simple tool that solves it without unnecessary features.

## Instructions

I want to make a small useful app that helps [person] with [everyday problem]. Interview me to understand the workflow. Create a short project brief with three essential features, a minimal data model, privacy considerations and test cases. Then guide me through building one feature at a time. Start with a browser-local prototype if suitable.
